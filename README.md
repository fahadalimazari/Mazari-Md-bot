## 🛠️ Installation & Setup (Local Server)

Run Mazari MD on your own PC or VPS in a few simple steps!

### 1. Fork & Clone
```bash
git clone https://github.com/fahadalimazari/Mazari-Md-bot.git
cd Mazari-Md-bot
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configuration
- Open `settings.js` to configure your VIP settings.
- Add your **Owner Number** and **Bot Name**.

### 4. Start the Bot
```bash
npm start
```
*Scan the QR code printed on your terminal using WhatsApp "Linked Devices".*
